Стальной залп — морской бой красками

КАК ЗАПУСТИТЬ
  Дважды щёлкнуть Igrat.bat
  или в этой папке набрать:  py -3.14 main.py

ЧТО НУЖНО
  Python 3.14 (на Windows — с запускателем py) и библиотека pygame-ce:
    py -3.14 -m pip install pygame-ce
  (или: py -3.14 -m pip install -r requirements.txt)
  Если стоит обычный pygame, его лучше удалить: pygame и pygame-ce мешают друг другу.

УПРАВЛЕНИЕ
  Мышь — всё основное: кнопки, выбор порта на карте, выстрел по клетке поля противника.
  Щелчок, пробел или Enter — дальше (пролог, разговоры).
  Esc — пропустить, назад, отмена.
  Расстановка: тащить корабль мышью; щелчок по кораблю, правая кнопка мыши или R — поворот;
    щелчок по воде — поставить мину.
  Бой: 1–4 — умения (купленные на верфи), затем щелчок по клетке поля противника.
  F11 — полный экран или окно.

СОХРАНЕНИЕ
  Игра сама создаёт progress.json в этой папке. Удалить его — начать с нуля.
